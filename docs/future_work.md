# TinyIDS Future Research & Extensions

1. **Multi-Device Federated Learning**: Aggregating behavioral model updates across multiple distributed Nano ESP32 endpoints without centralized raw data transmission.
2. **FreeRTOS Task-Level Profiling**: Instrumenting FreeRTOS task runtime statistics to identify specific hijacked threads.
3. **Dynamic Baseline Adaptation**: Slow online adaptation of baseline parameters to accommodate legitimate long-term network changes without susceptibility to model poisoning.
